INTRODUCCIÓN
=============

Este documento describe el funcionamiento completo del motor de partidos FM08-Engine v1.0,
desarrollado a partir del análisis exhaustivo de un archivo PKM real de Football Manager 2008.

El motor es capaz de simular partidos de fútbol completos con realismo estadístico,
basándose en patrones observados en el análisis binario del archivo PKM.

   SISTEMA DE MOVIMIENTO:
   --------------------
   MÉTODO move_towards(target, max_distance):
   
   - Algoritmo:
     1. Calcular distancia euclidiana al objetivo
     2. Si distancia ≤ max_distance: ir directamente al objetivo
     3. Si distancia > max_distance: mover proporcionalmente
     
   - Fórmulas Matemáticas:
     
     Distancia: d = √((x2-x1)² + (y2-y1)²)
     
     Movimiento Proporcional:
     ratio = max_distance / d
     nueva_x = x_actual + (x_objetivo - x_actual) * ratio
     nueva_y = y_actual + (y_objetivo - y_actual) * ratio
     
   - Parámetros:
     * max_distance: 50-200 unidades por movimiento
     * Validación de límites: 0 ≤ nueva_posición ≤ 1000
     * Movimiento promedio: 100 unidades

5. LÓGICA DE SIMULACIÓN POR MINUTOS
   =================================

   FLUJO PRINCIPAL (90 MINUTOS):
   ----------------------------
   
   PARA CADA MINUTO (1-90):
   
   1. GENERACIÓN DE EVENTOS:
      - Número de eventos: distribución aleatoria ponderada
        * Probabilidad más alta: 4-6 eventos/minuto
        * Rango: 2-15 eventos/minuto extremos
      
      - Selección de tipo de evento:
        * Basado en distribución de probabilidades
        * Usando random.choices() con pesos específicos
      
      - Asignación de equipo y jugador:
        * Selección aleatoria entre equipos
        * Jugador aleatorio del equipo seleccionado
        * Consideración de eventos previos del mismo minuto
      
   2. GENERACIÓN DE COORDENADAS:
      - Coordenada inicial:
        * Posición actual del jugador ± 50 unidades (ruido)
        * Validación dentro del campo (0-1000)
      
      - Coordenadas adicionales (1-4 posiciones):
        * Patrón específico por tipo de evento
        * Movimientos progresivos entre posiciones
        * Cálculo de distancias de movimiento

   3. ACTUALIZACIÓN DE ESTADOS:
      - Balón:
        * Posición aleatoria ±200 unidades
        * Validación de límites del campo
      
      - Jugadores:
        * Movimiento hacia posición del balón
        * Variación aleatoria ±100 unidades
        * Límite de distancia: 50-150 unidades
      
      - Estadísticas del equipo:
        * Goles, tarjetas, lesiones acumuladas
        * Actualización en tiempo real

   4. REGISTRO DE EVENTOS:
      - Estructura de MatchEvent:
        * minute: int                    # Minuto del partido
        * event_type: int                # Código de evento (0-19)
        * player_id: int                 # ID del jugador
        * player_name: str               # Nombre del jugador
        * team_id: int                  # ID del equipo
        * coordinates: List[float]        # Lista de coordenadas
        * description: str               # Descripción legible
        * movement_distance: float        # Distancia total movida

7. SISTEMA DE GENERACIÓN DE COORDENADAS
   ====================================

   FUNCIÓN generate_coordinates(event_type, current_pos):
   ===============================================
   
   ALGORITMO:
   ---------
   
   1. Coordenada Inicial:
      x = max(0, min(1000, current_pos.x + random(-50, 50)))
      y = max(0, min(1000, current_pos.y + random(-50, 50)))
      coords.extend([x, y])
   
   2. Coordenadas Adicionales (Por tipo de evento):
      
      GOLES (1):
         goal_x = random.choice([100, 900])
         goal_y = random.uniform(300, 700)
         coords.extend([goal_x, goal_y])
      
      ESQUINAS (8):
         corner_x = random.choice([50, 950])
         corner_y = random.choice([50, 950])
         coords.extend([corner_x, corner_y])
      
      TARJETAS (2,3):
         card_x = random.uniform(200, 600)
         card_y = random.uniform(200, 800)
         coords.extend([card_x, card_y])
      
      PASES/REGATES (14,15):
         PARA i EN [1, 2]:  # 2-3 posiciones adicionales
            next_x = max(0, min(1000, x + random(-150, 150)))
            next_y = max(0, min(1000, y + random(-150, 150)))
            coords.extend([next_x, next_y])
            x, y = next_x, next_y
   
   3. Validación:
      - Máximo 4 pares de coordenadas (8 valores)
      - Coordenadas dentro de rango [0, 1000]
      - Distancias realistas entre posiciones

   PATRONES DE MOVIMIENTO:
   ----------------------
   - Mínimo: 0 unidades (eventos estáticos)
   - Promedio: 100 unidades
   - Máximo: 840 unidades (observado en PKM)
   - Típico: 50-200 unidades por movimiento
